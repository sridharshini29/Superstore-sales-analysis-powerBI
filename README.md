# Superstore-sales-analysis-powerBI
Superstore sales analysis dashboard using microsoft powerBI
Superstore Sales Analysis Dashboard | Power BI

Project Overview

This project analyzes Superstore sales data using Microsoft Power BI to identify sales trends, profit performance, and business insights through an interactive dashboard.

Objectives

- Analyze overall sales and profit performance.
- Identify top-performing product categories and regions.
- Understand sales trends over time.
- Support data-driven business decisions.

Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
